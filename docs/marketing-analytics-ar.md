# التحليلات التسويقية (البند 10 – الإصدار 2.2)

## الهدف
معرفة **أي إعلان أو حملة بتجيب طلاب بيدفعوا فعلًا**.

## ليه مفيدة
1. **تعرف مين بيجيب الفلوس**: لكل مصدر (فيسبوك، جوجل، تيك توك…) هتشوف الزيارات والتسجيلات والمشترين والإيراد.
   مثال: تيك توك بيجيب ٨٠٠٠ زيارة بس طالبين اشتروا، وجوجل بيجيب ١٢٠٠ زيارة و٣٠ اشتروا. يبقى جوجل هو الأحسن.
2. **توقف الصرف الضايع**: تقلل الحملات اللي بتجيب زيارات من غير مبيعات، وتنقل الميزانية للي بتبيع.
3. **إعلانات أذكى**: جوجل وميتا بيستقبلوا حدثي التسجيل والشراء، فبيستهدفوا ناس شبه اللي اشتروا مش أي حد بيدوس على الإعلان، وتقدر تعيد استهداف اللي سجلوا وما اشتروش.
4. **قانوني**: مفيش تتبع قبل موافقة الزائر.

## اللي اتنفذ (`local_nit_analytics`)
1. **شريط موافقة**: لا يتحمّل أي تتبع قبل "موافق".
2. **ربط GA4 وTag Manager وMeta Pixel** من الإعدادات، من غير مبرمج.
3. **حفظ مصدر الحملة** (`utm_source`) ٩٠ يوم، ويتسجل على حساب الطالب عند التسجيل.
4. **إرسال الأحداث**: `sign_up` و`purchase` (كورس، باقة فلكس، اشتراك) بالمبلغ والعملة. إضافة الأدمن لا تُحسب كشراء إعلاني.
5. **تقرير مسار الاكتساب**: زيارات ← تسجيلات ← مشترين ← إيراد لكل مصدر وحملة، مع تنزيل CSV.

## غير منفذ بعد
- رسوم بيانية للإيراد لكل قناة داخل الموقع (متاحة في GA4 وMeta Ads بعد وصول الأحداث).
- الأحداث من السيرفر (Meta Conversions API) لمن يحجب الـ Pixel.

## خطوات التشغيل
1. **GA4**: analytics.google.com ← Admin ← Create property (توقيت القاهرة، عملة EGP) ← Web data stream ← انسخ `G-XXXXXXX`.
2. **Meta Pixel**: business.facebook.com ← Events Manager ← Connect data ← Web ← انسخ رقم الـ Pixel.
3. **(اختياري) GTM**: tagmanager.google.com ← انسخ `GTM-XXXXXXX`. لو استخدمته ما تحطش GA4 في الموقع كمان (عشان ما يتحسبش مرتين).
4. **في الموقع**: إدارة الموقع ← Plugins ← Local plugins ← **Marketing analytics** ← الصق الأكواد، وسيب "Ask for consent first" مفعّل ← Save.
5. **روابط الإعلانات**: أضف UTM لكل رابط، مثال:
   `https://academy2026.nitg-eg.com/jitsi_life/?utm_source=facebook&utm_medium=cpc&utm_campaign=oct_english`
6. **اختبار**: افتح الموقع في نافذة خاصة ← "موافق" ← تأكد من ظهورك في GA4 ← Realtime وفي Meta ← Test events.
7. **اختبار التحويل**: سجّل واشترِ بحساب تجريبي ← تأكد من وصول `sign_up` و`purchase`.
8. **في GA4**: Admin ← Events ← علّم `purchase` و`sign_up` كـ **Key events**.
9. **المتابعة**: إدارة الموقع ← التقارير ← **Acquisition funnel** ← نزّل CSV أسبوعيًا لفريق التسويق.
