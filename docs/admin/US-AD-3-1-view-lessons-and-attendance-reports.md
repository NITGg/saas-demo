# **US-AD-3-1: View Lessons and Attendance Reports**

### **As an** admin, **I want to** view lessons, teachers, students, attendance, and activity reports, **So that** I can monitor learning activity across the platform.

## **Flow**

### 1. **🔧 Admin** → Opens lesson and report management

2. **⚙️ System** → Displays lessons, teachers, students, and attendance data

3. **🔧 Admin** → Filters and opens the required record

4. **⚙️ System** → Displays the related details and reports

5. **🔧 Admin** → Exports attendance or Flex reports as CSV or PDF

## **Included Features**

### - View all lessons across all courses

- View teachers and their lesson schedules

- View the attendance history of each participant

- View student information and login history

- View attendance reports for all live lessons

- Export attendance and Flex reports as CSV or PDF

- View student attendance for each live lesson

- View the student's overall attendance percentage across all lessons

- View the student's activity report inside each course

- Per-lesson \*\*action timeline\*\* — the time of every student/teacher/system action on the request (created, accepted, rejected, suggested, started, completed, cancelled, absence reported, time-update). Timestamps are stored encrypted and decrypted for display. See \[audit trail]\(../00-overview\.md#lesson-action-audit-trail).

## **الخصائص المتضمنة**

### - استعراض جميع الحصص في جميع الكورسات

- استعراض المدرسين ومواعيد حصصهم

- الاطلاع على سجل الحضور لكل مشارك

- استعراض بيانات الطالب وسجل دخوله

- استعراض تقارير الحضور لجميع الحصص المباشرة

- تصدير تقارير الحضور والكريدت بصيغة CSV أو PDF

- استعراض حضور الطالب في كل حصة مباشرة

- استعراض نسبة الحضور الإجمالية للطالب عبر جميع حصصه

- استعراض تقرير نشاط الطالب داخل كل كورس

- استعراض الخط الزمني لكل إجراء على الحصة (الإنشاء، القبول، الرفض، الاقتراح، البدء، الإكمال، الإلغاء، تسجيل الغياب، طلب تعديل الوقت) — تُخزَّن أوقات الإجراءات مشفّرة وتُفك للعرض

## **Notes**

### - The admin can filter by course, teacher, student, date, lesson status, or attendance status.

- Exported reports should follow the selected filters.
