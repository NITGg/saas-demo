## **US-AD-1-2: Update a Lesson Package**

**As an** admin,\
**I want to** update a lesson package and its offer,\
**So that** I can manage pricing and promotions.
------------------------------------------------

## **Flow**

## 1. 🔧 Admin → Opens package management

2. 🔧 Admin → Selects a package

3. 🔧 Admin → Updates package information

### **Offer Update**

## 4. 🔧 Admin → Enables / disables offer

5. 🔧 Admin → Updates discount value or dates

6. 🔧 Admin → Saves changes

7. ⚙️ System → Updates package and recalculates price

## **Notes**

## - Changes apply only to future purchases.

- Existing purchases keep original price.

- Offer changes do not affect active packages.
