## **US-AD-1-1: Create a Lesson Package**

### **As an** admin, **I want to** create a lesson package with optional offer, **So that** students can purchase Flexes with promotional pricing.

## **Flow**

### 1. 🔧 Admin → Opens package management

2. 🔧 Admin → Taps "Create Package"

3. 🔧 Admin → Enters the package name

4. 🔧 Admin → Adds a package description

5. 🔧 Admin → Enters the number of Flexes

6. 🔧 Admin → Enters the price

### **Offer Settings (Optional)**

### 7. 🔧 Admin → Enables `Offer`

8. 🔧 Admin → Selects discount type (percentage / fixed)

9. 🔧 Admin → Enters discount value

10. 🔧 Admin → Sets offer start date

11. 🔧 Admin → Sets offer end date

12. 🔧 Admin → Sets the expiration period

13. 🔧 Admin → Activates the package

14. ⚙️ System → Calculates discounted price

15. ⚙️ System → Displays package to students

## **Notes**

### - Offer is optional.

- Only one offer per package.

- Offer is applied automatically during active period.

- Final price cannot be less than zero.

- Deactivating package does not affect purchased ones.

- Offer applies only to future purchases.
