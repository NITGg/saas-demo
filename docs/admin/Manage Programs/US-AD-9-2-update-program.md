## **US-AD-9-2: Update a Program**

**As an** admin,\
**I want to** update a program and its offer,\
**So that** I can manage its content and pricing.
=================================================

## **Flow**

# 1. 🔧 Admin → Opens program management

2. 🔧 Admin → Selects a program

3. 🔧 Admin → Updates:

   - Name

   - Description

   - Courses list

   - Price***

### **Offer Update**

# 4. 🔧 Admin → Enables / disables offer

5. 🔧 Admin → Updates discount type, value, or dates***

## **Save Changes**

# 6. 🔧 Admin → Saves changes

7. ⚙️ System → Updates program

8. ⚙️ System → Recalculates price

## **Notes**

# - Changes apply only to future purchases.

- Existing purchases keep original price and course access.

- Removing a course does not affect users who already purchased the program.

- Offer updates do not affect previous purchases.
