## **US-AD-8-2: Update an Offer**

**As an** admin,\
**I want to** update an offer,\
**So that** I can modify its behavior.


## **Flow**

1. 🔧 Admin → Opens offer management

2. 🔧 Admin → Selects an offer

3. 🔧 Admin → Updates discount, scope, or dates

4. 🔧 Admin → Saves changes

5. ⚙️ System → Applies changes to future purchases


## **Notes**

- Changes do not affect past purchases.

- Updated offer applies only moving forward.
