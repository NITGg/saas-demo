# **US-AD-7-2: Update a Coupon**

**As an** admin,\
**I want to** update a coupon,\
**So that** I can modify its behavior.
--------------------------------------

## **Flow**

## 1. 🔧 Admin → Opens coupon management

2. 🔧 Admin → Selects a coupon

3. 🔧 Admin → Updates discount, limits, or dates

4. 🔧 Admin → Saves changes

5. ⚙️ System → Applies changes to future usage

## **Notes**

## - Changes do not affect already used coupons.
