# **US-AD-10-2: Assign Certificate to Program**

**As an admin,**I want to assign a certificate template to a program,\
So that students receive a certificate after completing all required courses within the program.
================================================================================================

## **Flow**

# 👨‍💼 Admin → Opens the program details👨‍💼 Admin → Enables **Program Certificate**👨‍💼 Admin → Selects a certificate template👨‍💼 Admin → Saves the configuration⚙️ System → Links the certificate template to the program⚙️ System → Automatically issues the certificate when the student completes all required courses in the program

## **Notes**

# - Assigning a certificate is optional.

- Students must complete all required courses before the certificate is issued.

- Optional courses do not prevent certificate issuance.

- Existing issued certificates are not affected by future configuration changes.
