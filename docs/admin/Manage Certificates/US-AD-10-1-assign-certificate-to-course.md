# **US-AD-10-1: Assign Certificate to Course**

**As an admin,**I want to assign a certificate template to a course,\
So that students automatically receive a certificate after completing the course requirements.
==============================================================================================

## **Flow**

# 👨‍💼 Admin → Opens the course details👨‍💼 Admin → Enables **Course Certificate**👨‍💼 Admin → Selects a certificate template👨‍💼 Admin → Configures the certificate completion requirements⚙️ System → Validates the configuration⚙️ System → Saves the certificate settings

## **Notes**

# - Assigning a certificate is optional.

- Only one active certificate template can be assigned to a course.

- Existing issued certificates are not affected by future configuration changes.

- The certificate is issued automatically once all completion requirements are satisfied.
