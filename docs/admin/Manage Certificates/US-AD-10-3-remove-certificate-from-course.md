# **US-AD-10-3: Remove Certificate from Course**

**As an admin,**I want to remove the assigned certificate from a course,\
So that the course no longer issues certificates to students.
=============================================================

## **Flow**

# 👨‍💼 Admin → Opens the course details👨‍💼 Admin → Opens the **Certificate** settings👨‍💼 Admin → Clicks **Remove Certificate**⚙️ System → Displays a confirmation message👨‍💼 Admin → Confirms the removal⚙️ System → Removes the certificate assignment from the course⚙️ System → Saves the updated course settings

## **Notes**

# - Removing the certificate only affects future certificate issuance.

- Previously issued certificates remain valid and accessible.

- The course can have no certificate assigned after removal.

- The admin can assign another certificate at any time.
