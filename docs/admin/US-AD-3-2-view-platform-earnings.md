# **US-AD-3-2: View Platform Earnings**

**As an** admin,\
**I want to** view the platform earnings,\
**So that** I can track the platform revenue from lessons.
==========================================================

## **Display**

# - Completed lesson

- Teacher name

- Student name

- Lesson date

- Flex value

- Platform percentage

- Platform earning amount

- Transaction status

## **Summary**

# - Total platform earnings

- Total teacher earnings

- Total consumed Flex value

- Number of completed lessons

## **Notes**

# - Only permanently consumed Flexes generate platform earnings.

- Returned Flexes do not generate earnings.

- Earnings use the percentages active when the Flex was consumed.

- Admin can filter earnings by date, teacher, and transaction status.
