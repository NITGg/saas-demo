# **US-AD-3-3: View Package and Flex Reports**

**As an** admin,\
**I want to** view package sales, Flex usage, and refund reports,\
**So that** I can track package and Flex transactions across the platform.
==========================================================================

## **Reports**

# - Package sales

- Packages assigned by admins

- Purchased and assigned Flexes

- Consumed Flexes

- Returned Flexes

- Expired Flexes

- Payment refunds

- Financial reversals

## **Filters**

# - Student

- Package

- Transaction type

- Payment method

- Date

- Transaction status

## **Summary**

# - Total package sales

- Total assigned packages

- Total Flexes added

- Total Flexes consumed

- Total Flexes returned

- Total refunded amount

## **Actions**

# - View transaction details

- Export report as CSV

## **Notes**

# - Online and external package payments must be identified separately.

- Returned Flexes and monetary refunds must be shown as different transaction types.

- Exported reports follow the selected filters.
