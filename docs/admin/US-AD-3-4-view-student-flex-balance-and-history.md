# **US-AD-3-4: View Student Flex Balance and History**

**As an** admin,\
**I want to** view a student's Flex balance and transaction history,\
**So that** I can review every change made to the student's balance.
====================================================================

## **Display**

# - Available Flexes

- Reserved Flexes

- Consumed Flexes

- Expired Flexes

- Active package

- Package expiration date

## **Transaction History**

# - Transaction date

- Transaction type

- Flex amount

- Balance before

- Balance after

- Related package

- Related lesson

- Performed by

- Reason or notes

## **Transaction Types**

# - Package purchase

- Package assigned by admin

- Flex reserved

- Flex consumed

- Flex returned

- Flex expired

- Admin adjustment

## **Actions**

# - Filter transactions

- View transaction details

- Export history as CSV

## **Notes**

# - Every Flex balance change must create a transaction record.

- The admin can only adjust the balance through an authorized action.

- The system records the admin who performs a manual adjustment.
