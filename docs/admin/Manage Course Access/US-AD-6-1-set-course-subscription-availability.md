# **US-AD-6-1: Set Course Subscription Availability**

**As an** admin,\
**I want to** select which subscriptions can access a course,\
**So that** only eligible students can view its content.
========================================================

## **Flow**

# 1. **🔧 Admin** → Opens course management

2. **🔧 Admin** → Selects a course

3. **🔧 Admin** → Opens subscription access settings

4. **🔧 Admin** → Selects all subscriptions or specific subscriptions

5. **🔧 Admin** → Saves the changes

6. **⚙️ System** → Applies the new course access rules

## **Example**

# - Arabic course → Available with all subscriptions

- English course → Available only with the 365-day subscription

## **Notes**

# - The student must have an active, unexpired subscription.

- The student's subscription must match one of the course subscriptions.

- Course access changes apply immediately.
