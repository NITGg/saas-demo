# **US-TR-1-1: Update Teacher Profile**

**As a** teacher,\
**I want to** update my profile and working hours,\
**So that** students can see my current information and availability.

***


## **Flow**

1. **👨‍🏫 Teacher** → Opens profile settings

2. **👨‍🏫 Teacher** → Updates personal or teaching information

3. **👨‍🏫 Teacher** → Updates available days and working hours

4. **👨‍🏫 Teacher** → Taps "Save Changes"

5. **⚙️ System** → Validates the changes

6. **⚙️ System** → Updates the teacher profile

7. **⚙️ System** → Displays the updated information to students


## **Notes**

- Working hours must not overlap.

- Confirmed lesson times cannot be removed.

- Important profile changes may require admin approval.
