# **US-TR-1-2: View Related Lessons**

**As a** teacher,\
**I want to** view my lesson requests and lessons,\
**So that** I can respond to students and manage my teaching schedule.
======================================================================

## **Flow**

# 1. **👨‍🏫 Teacher** → Opens the "My Lessons" screen

2. **⚙️ System** → Displays lessons related to the teacher

3. **👨‍🏫 Teacher** → Filters lessons by status

4. **👨‍🏫 Teacher** → Selects a lesson

5. **⚙️ System** → Displays the lesson details (student, date, notes, cancellation reason, attendance report, etc.)

6. **⚙️ System** → Displays the actions available for the current status

## **Available Actions**

# Depending on the lesson status, the teacher can:* Accept the lesson request

* Reject the lesson request

* Suggest another time

* Accept the student's suggested time

* Cancel a confirmed lesson

* Start the lesson

* Complete the lesson

* Report student absence

* View lesson details

## **Notes**

# - The teacher can only view lessons related to their own account.

- Pending and waiting-for-teacher requests should appear first.

- Upcoming confirmed lessons should be ordered by date and time.

- Completed, rejected, and cancelled lessons should remain available in lesson history.
