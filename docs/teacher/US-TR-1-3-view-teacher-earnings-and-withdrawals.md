# **US-TR-1-3: View Teacher Earnings and Withdrawals**

**As a** teacher,\
**I want to** view my earnings and withdrawal history,\
**So that** I can track my available balance and withdrawn money.
=================================================================

## **Earnings Summary**

# - Total earnings

- Available balance

- Reserved withdrawal amount

- Total withdrawn amount

## **Lesson Earnings**

# - Completed lesson

- Student name

- Lesson date

- Flex value

- Teacher percentage

- Earning amount

- Earning status

## **Withdrawal History**

# - Withdrawal amount

- Request date

- Withdrawal method

- Payment reference

- Withdrawal status

- Rejection reason

## **Actions**

# - Request withdrawal

- View withdrawal details

## **Notes**

# - Only consumed Flexes generate earnings.

- Returned Flexes reverse the related earnings.

- Pending withdrawal amounts are reserved and cannot be withdrawn again.

- Withdrawal statuses are `Pending`, `Approved`, `Rejected`, and `Paid`.
