# **US-TR-2-1: Export Teacher Reports**

**As a** teacher,\
**I want to** download my reports as PDF or CSV,\
**So that** I can keep a record of my lessons, earnings, and withdrawals.
=========================================================================

## **Flow**

# 1. **Teacher** → Opens reports

2. **Teacher** → Selects the report type

3. **Teacher** → Applies filters

4. **Teacher** → Selects PDF or CSV

5. **⚙️ System** → Generates and downloads the report

## **Report Types**

# - Lesson earnings report

- Withdrawal history report

- Earnings and withdrawals summary

- Completed lessons report

- Attendance report

- Cancelled lessons report

## **Financial Report Data**

# - Total earnings

- Available balance

- Reserved withdrawal amount

- Total withdrawn amount

- Flex value

- Teacher percentage

- Earning amount

- Withdrawal amount and status

## **Notes**

# - The teacher can only export their own data.

- Reports follow the selected date and status filters.

- Reversed earnings are shown in financial reports.

- Withdrawal reports include pending, approved, rejected, and paid requests.
