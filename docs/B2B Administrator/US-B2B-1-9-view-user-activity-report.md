### **US-B2B-1-9: View User Activity Report**

### **As an admin,**I want to view an activity report for each user, So that I can monitor their actions and subscription usage.

#### **Flow**

### 🔧 Admin → Opens user management 🔧 Admin → Selects a user 🔧 Admin → Opens **Activity Report**⚙️ System → Displays the user’s activity details

#### **Report Information**

### - Registration date

- Last login date

- Current role

- Active subscriptions

- Subscription expiration dates

- Courses accessed

- B2B memberships

- Account status

- Recent important actions

#### **Notes**

### - The admin can filter the report by date.

- The admin can view only activities recorded by the system.

- Subscription and payment history must remain available even after expiration.

- Sensitive information must be visible only to authorized admins.
