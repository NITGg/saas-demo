## **US-US-OF-1-1: View Available Offers**

**As a** user,\
**I want to** view available offers,\
**So that** I can know which items have discounts.
==================================================

## **Flow**

# 1. 🎓 User → Opens courses / packages / subscriptions

2. ⚙️ System → Displays items with active offers

3. 🎓 User → Views item details

## **Display**

# - Item name (course / package / subscription)

- Original price

- Discount type

- Discount value

- Discounted price

- Offer valid dates

## **Notes**

# - Offers are applied automatically.

- Offers may apply to:

  - One course

  - Multiple courses

  - One package

  - One subscription

- Only items included in the offer scope show discounts.
