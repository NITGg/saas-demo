# US-ST-1-1: Student Registration

[← spec index](../README.md) · Area: Student · **Status:** Spec

As a new student, I want to create an account, so that I can purchase packages and request lessons.

## Flow
1. 🎓 Open registration → enter personal info
2. 🎓 Enter phone or email → create password → tap "Register"
3. ⚙️ Validate → send verification code
4. 🎓 Enter verification code → ⚙️ verify → activate account

## Notes
- Phone/email must be unique.
- After registration the student can browse teachers and packages.
