# **US-SB-1-1: View Available Subscriptions**

**As a** student,\
**I want to** view available subscription plans,\
**So that** I can select a suitable plan.
=========================================

## **Flow**

# 1. **🎓 Student** → Opens the subscriptions screen

2. **⚙️ System** → Displays active subscriptions

3. **🎓 Student** → Selects a subscription

4. **⚙️ System** → Displays its details

## **Display**

# - Subscription name

- Price

- Number of days

- Description

- Available courses
