# **US-US-CP-1-3: View My Coupons and Usage History**

**As a** user,\
**I want to** view my used coupons,\
**So that** I can track my discounts.
-------------------------------------

## **Flow**

## 1. 🎓 User → Opens `My Coupons`

2. ⚙️ System → Displays used coupons

3. 🎓 User → Views usage details

## **Display**

## - Coupon code

- Discount applied

- Used date

- Related purchase

- Final paid amount

## **Notes**

## - Only used coupons are shown.

- One-time coupons cannot be reused.

- Multi-use coupons follow their usage limits.
