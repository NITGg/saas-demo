# **US-US-10-1: View & Download My Certificates**

**As a student,**I want to view and download my earned certificates,\
So that I can keep proof of completing my courses and programs.
---------------------------------------------------------------

## **Flow**

## 🎓 Student → Opens **My Certificates**⚙️ System → Displays all issued certificates🎓 Student → Selects a certificate⚙️ System → Displays the certificate details and preview🎓 Student → Clicks **Download PDF**⚙️ System → Generates or retrieves the certificate PDF⚙️ System → Starts the download

## **Notes**

## - Only issued certificates are displayed.

- Certificates are grouped by Course and Program.

- Each certificate displays its issue date and current status.

- Only issued certificates can be downloaded.

- Every certificate includes a unique certificate number and verification code.

- Downloading a certificate does not affect its validity.
