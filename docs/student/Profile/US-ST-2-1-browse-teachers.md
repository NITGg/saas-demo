# **US-ST-2-1: Browse Teachers**

**As a** student,\
**I want to** browse available teachers,\
**So that** I can find a suitable teacher.***
=============================================

## **Flow**

# 1. **🎓 Student** → Opens the teachers screen

2. **⚙️ System** → Displays approved and available teachers

3. **🎓 Student** → Filters teachers by subject or specialization

4. **🎓 Student** → Selects a teacher

5. **⚙️ System** → Displays the teacher profile

## **Notes**

# The teacher profile can display:* Name

* Profile image

* Subjects

* Specializations

* Experience

* Available times

* Rating

* Reviews

* Short biography
