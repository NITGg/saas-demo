# **US-ST-2-2: Views Related Lessons**

**As a** student,\
**I want to** view my lesson requests and lessons,\
**So that** I can follow their status and manage my schedule.***
================================================================

## **Flow**

# 1. **🎓 Student** → Opens the "My Lessons" screen

2. **⚙️ System** → Displays lessons related to the student

3. **🎓 Student** → Filters lessons by status

4. **🎓 Student** → Selects a lesson

5. **⚙️ System** → Displays the lesson details (teacher, date, reject reason, Attendance Report, etc.)

6. **⚙️ System** → Displays the actions available for the current status

## **Available Actions**

# Depending on the lesson status, the student can:* Cancel the request

* Accept a suggested time

* Suggest another time

* Cancel a confirmed lesson

* Report teacher absence

* View lesson details

## **Notes**

# - The student can only view lessons related to their own account

- Upcoming confirmed lessons should appear first.

- Upcoming lessons inactive until teacher start leasson

- Completed and cancelled lessons should remain available in lesson history.

- The system should show whether a Flex is available, reserved, returned, or used.
