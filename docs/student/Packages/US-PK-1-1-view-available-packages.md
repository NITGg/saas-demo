# **US-PK-1-1: View Available Packages**

**As a** student,\
**I want to** view available lesson packages,\
**So that** I can select a suitable package.***
===============================================

## **Flow**

# 1. **🎓 Student** → Opens the packages screen

2. **⚙️ System** → Displays active packages

3. **🎓 Student** → Selects a package

4. **⚙️ System** → Displays the package details

5. **🎓 Student** → Reviews the package

## **Notes**

# Package details include:* Package name

* Number of Flexes

* Price

* Expiration period

* Description
