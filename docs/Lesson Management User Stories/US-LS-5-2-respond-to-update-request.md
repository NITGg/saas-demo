# **US-LS-5-2: Response Update Request**

**As a** student or teacher,\
**I want to** respond to a lesson time-update request,\
**So that** I can accept or reject the requested time.
======================================================

## **Flow**

# 1. **🎓 Student / 👨‍🏫 Teacher** → Opens the time-update request

2. **🎓 Student / 👨‍🏫 Teacher** → Reviews the requested time

3. **🎓 Student / 👨‍🏫 Teacher** → Selects one action:

   - Accept

   - Reject

4. **⚙️ System** → Updates the time-update request

5. **⚙️ System** → Notifies the other user

## **Results**

# - **Accept** → The lesson moves to the new confirmed time

- **Reject** → The original confirmed time remains unchanged

## **Notes**

# - The requested time must still be available when accepted.

- The original confirmed time remains active until the update is accepted.

- Rejecting the update does not cancel the lesson.

- The student's reserved Flex is not affected.
