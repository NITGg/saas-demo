# **US-LS-4-1: Cancel a Lesson as a Student**

**As a** student,\
**I want to** cancel a confirmed lesson,\
**So that** the teacher knows I cannot attend.***
=================================================

## **Flow**

# 1. **🎓 Student** → Opens a confirmed lesson

2. **🎓 Student** → Taps "Cancel Lesson"

3. **⚙️ System** → Checks the cancellation deadline

4. **🎓 Student** → Confirms the cancellation

5. **⚙️ System** → Changes the lesson status to "Cancelled"

6. **⚙️ System** → Applies the cancellation policy

7. **⚙️ System** → Notifies the teacher

## **Notes**

# - An early cancellation can return the reserved Flex.

- A late cancellation consume the Flex.

- The cancellation deadline is configured by the admin.
