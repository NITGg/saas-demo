# **US-LS-3-4: Report Teacher Absence**

**As a** student,\
**I want to** report that a teacher did not attend,\
**So that** my Flex can be returned.***
=======================================

## **Flow**

# 1. **🎓 Student** → Opens the confirmed lesson

2. **🎓 Student** → Waits for the teacher

3. **🎓 Student** → Taps "Teacher Absent"

4. **⚙️ System** → Records the report

5. **⚙️ System** → Changes the status to "Teacher Absent"

6. **⚙️ System** → Returns the reserved Flex

7. **⚙️ System** → Notifies the teacher and admin

## **Notes**

# - The admin can review the case.

- Repeated teacher absences may lead to suspension.
