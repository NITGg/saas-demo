# **US-LS-4-2: Cancel a Lesson as a Teacher**

**As a** teacher,\
**I want to** cancel a confirmed lesson,\
**So that** the student can use the Flex for another lesson.***
===============================================================

## **Flow**

# 1. **👨‍🏫 Teacher** → Opens a confirmed lesson

2. **👨‍🏫 Teacher** → Taps "Cancel Lesson"

3. **👨‍🏫 Teacher** → Enters a cancellation reason

4. **👨‍🏫 Teacher** → Confirms the cancellation

5. **⚙️ System** → Changes the status to "Cancelled by Teacher"

6. **⚙️ System** → Returns the reserved Flex

7. **⚙️ System** → Releases the lesson time

8. **⚙️ System** → Notifies the student

## **Notes**

# - A teacher cancellation should not consume the student's Flex.

- Repeated cancellations may be reviewed by the admin.
