# **US-LS-3-3: Report Student Absence**

**As a** teacher,\
**I want to** report that a student did not attend,\
**So that** the missed lesson can be handled correctly.***
==========================================================

## **Flow**

# 1. **👨‍🏫 Teacher** → Opens the confirmed lesson

2. **👨‍🏫 Teacher** → Waits for the student

3. **👨‍🏫 Teacher** → Taps "Student Absent"

4. **⚙️ System** → Records the absence

5. **⚙️ System** → Changes the status to "Student Absent"

6. **⚙️ System** → Applies the platform Flex policy

7. **⚙️ System** → Notifies the student

## **Notes**

# - The Flex may be deducted according to platform rules.

- The student may submit a dispute.

- The admin can review disputed cases.
