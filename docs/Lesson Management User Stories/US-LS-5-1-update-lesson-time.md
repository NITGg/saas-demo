# **US-LS-5-1: Update Lesson Time**

**As a** student or teacher,\
**I want to** request another time for a confirmed lesson,\
**So that** the lesson can be moved to a more suitable time.
============================================================

## **Flow**

# 1. **🎓 Student / 👨‍🏫 Teacher** → Opens a confirmed lesson

2. **🎓 Student / 👨‍🏫 Teacher** → Selects "Request Time Update"

3. **🎓 Student / 👨‍🏫 Teacher** → Selects another available time

4. **⚙️ System** → Checks the time-update deadline

5. **⚙️ System** → Checks that the new time is available

6. **⚙️ System** → Sends the request to the other user

7. **⚙️ System** → Notifies the other user

## **Notes**

# - Either the student or teacher can request a time update.

- The request must be made before the configured deadline.

- The original lesson remains confirmed until the new time is accepted.

- The student's Flex remains reserved.

- No additional Flex is reserved.

- Only one active time-update request is allowed for each lesson
