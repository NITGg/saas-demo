## **US-FN-1-4: Distribute Lesson Revenue**

**As a** system,\
**I want to** distribute the Flex value after a completed lesson,\
**So that** the teacher and platform receive their shares.
----------------------------------------------------------

### **Flow**

## 1. **Teacher** → Completes the lesson

2. **⚙️ System** → Consumes the reserved Flex

3. **⚙️ System** → Adds 40% of the Flex value to the teacher's earnings

4. **⚙️ System** → Adds 60% of the Flex value to the platform revenue

5. **⚙️ System** → Records the financial transaction

### **Example**

## - Flex value → 1 EGP

- Teacher earnings → 0.40 EGP

- Platform revenue → 0.60 EGP

### **Notes**

## - Revenue is distributed only when the Flex is permanently consumed.

- The percentage is calculated from the Flex value of the purchased package.***
