## **US-FN-1-3: Return a Reserved Flex**

**As a** system,\
**I want to** return a reserved Flex when required,\
**So that** the student does not lose it incorrectly.
-----------------------------------------------------

### **Flow**

## 1. **⚙️ System** → Receives a valid cancellation or absence result

2. **⚙️ System** → Returns the reserved Flex to the student

3. **⚙️ System** → Cancels any related teacher or platform earnings

### **Flex Return Cases**

## - Teacher cancels the lesson

- Teacher is absent

- Student cancels before the cancellation deadline

### **Notes**

## - No teacher earnings are added.

- No platform revenue is added.
