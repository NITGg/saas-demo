## **US-FN-1-1: Purchase a Flex Package**

**As a** student,\
**I want to** purchase a Flex package,\
**So that** I can use the Flexes to book lessons.
=================================================

### **Flow**

# 1. **Student** → Selects a package

2. **Student** → Completes payment

3. **⚙️ System** → Activates the package

4. **⚙️ System** → Adds the Flexes to the student's balance

5. **⚙️ System** → Records the value of each Flex

### **Example**

# - Package price → 20 EGP

- Package Flexes → 20 Flex

- One Flex value → 1 EGP

### **Notes**

# - Flex value is calculated from the package price divided by the Flex count.

- The payment is recorded in the student's payment history.
