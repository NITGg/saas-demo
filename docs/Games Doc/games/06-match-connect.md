# 🧩 وصل الصورة بالكلمة

| | |
|---|---|
| **المستوى** | ⭐ سهل |
| **المهارة** | ربط الكلمة بمعناها |

## الفكرة

صور على ناحية وكلمات على الناحية التانية،
والطفل يسحب كل كلمة ويحطها تحت صورتها.

## إزاي بتتلعب

1. تظهر 4 صور فوق
2. تحتيهم 4 كلمات مبعثرة
3. الطفل يسحب الكلمة ويحطها تحت الصورة الصح
4. صح → الكلمة تثبت وتتلوّن · غلط → ترجع مكانها

## مثال

> **الصور:** 🐱 🐶 🐦 🐟
> **الكلمات:** كلب · قطة · سمكة · عصفور

## النقاط والشارة

- نقطة لكل توصيلة صح
- 🏅 **"عين حادّة"** — لوحة كاملة من غير غلطة
