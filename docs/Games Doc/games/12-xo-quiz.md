# ❌⭕ XO التعليمي

| | |
|---|---|
| **المستوى** | ⭐ سهل |
| **المهارة** | أي مادة + تفكير |

## الفكرة

لعبة XO العادية، بس عشان تحط علامتك لازم تجاوب سؤال صح الأول.
بيلعبها مع الكمبيوتر أو مع طفل تاني على نفس الجهاز.

## إزاي بتتلعب

1. الطفل يختار خانة فاضية
2. يظهر سؤال
3. إجابة صح → العلامة تتحط في الخانة
4. إجابة غلط → الدور يروح للطرف التاني
5. 3 علامات في خط = كسب

## مثال

> الطفل يختار الخانة الوسط
> **سؤال:** كام ٥ + ٣؟ → `8` ✅
> ❌ تتحط في الوسط

## النقاط والشارة

- نقطة لكل إجابة صح + مكافأة لما يكسب الجولة
- 🏅 **"بطل الـ XO"** — 3 جولات مكسوبة
