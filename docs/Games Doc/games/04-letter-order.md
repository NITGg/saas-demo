# 🔤 رتب الحروف

| | |
|---|---|
| **المستوى** | ⭐ سهل |
| **المهارة** | التهجئة وتركيب الكلمات |

## الفكرة

حروف كلمة واحدة بتظهر مبعثرة، والطفل يرتّبها عشان تطلع الكلمة الصح.
معاه صورة تساعده.

## إزاي بتتلعب

1. تظهر صورة فوق
2. تحتيها حروف الكلمة مبعثرة
3. الطفل يسحب الحروف ويرتّبها
4. الكلمة تكمل صح → صوت تشجيع ونقطة

## مثال

> 🏫 **الصورة:** مدرسة
> **الحروف:** `ر` `م` `ة` `س` `د`
> **الإجابة:** م - د - ر - س - ة

## النقاط والشارة

- نقطة لكل كلمة صح
- 🏅 **"ملك الحروف"** — 15 كلمة صح
