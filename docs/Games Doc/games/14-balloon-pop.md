# 🎈 فرقعة البالونات

| | |
|---|---|
| **المستوى** | ⭐ سهل |
| **المهارة** | الأرقام أو الحروف |

## الفكرة

بالونات ملوّنة بتطلع لفوق، كل بالونة عليها رقم أو حرف.
الطفل يفرقع البالونة المطلوبة بس.

## إزاي بتتلعب

1. يظهر المطلوب فوق (مثلاً: "فرقّع حرف السين")
2. البالونات تبدأ تطلع
3. الطفل يضغط على البالونة الصح
4. صح → 💥 فرقعة وصوت مرح · غلط → البالونة تهتز وتفضل طايرة

## مثال

> **المطلوب: الأرقام الزوجية**
> بالونات طايرة: `3` `8` `5` `12` `7`
> يفرقّع: 8 و 12

## ملاحظة

> السؤال لازم يكون **قصير جدًا** — الطفل بيقراه والبالونة بتتحرك.

## النقاط والشارة

- نقطة لكل بالونة صح
- 🏅 **"مفرقّع محترف"** — 25 بالونة صح
