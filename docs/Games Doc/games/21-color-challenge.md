# 🎨 تحدي الألوان

| | |
|---|---|
| **المستوى** | ⭐ سهل |
| **المهارة** | تمييز الألوان |

## الفكرة

أبسط لعبة للصغيرين خالص — الطفل يختار اللون المطلوب أو يطابق لونين.
مش محتاجة قراية ولا أرقام.

## إزاي بتتلعب

1. يظهر لون كبير في النص + صوت بيقول اسمه
2. تحته دواير بألوان مختلفة
3. الطفل يضغط على اللون الصح
4. صح → اللون يكبر بصوت مرح

## مثال

> 🔊 **"دوّر على اللون الأحمر"**
> 🔵 🔴 🟢 🟡

## النقاط والشارة

- نقطة لكل لون صح
- 🏅 **"فنان صغير"** — كل الألوان الأساسية صح
