# 🧠 معلومات عامة

| | |
|---|---|
| **المستوى** | ⭐ سهل |
| **المهارة** | معلومات في أي مادة |

## الفكرة

أبسط لعبة في ركن الألعاب — سؤال و3 أو 4 اختيارات، والطفل يختار الصح.

**دي أهم لعبة**، لأن نفس الأسئلة بتتستخدم في ألعاب تانية كتير
زي XO والبالونات ورحلة الفضاء.

## إزاي بتتلعب

1. يظهر السؤال (مع صورة أو صوت لو موجود)
2. تحته الاختيارات
3. الطفل يختار
4. صح → ✅ وشرح قصير · غلط → 💪 "جرّب تاني"

## مثال

> **إيه أكبر كوكب في المجموعة الشمسية؟**
> `الأرض`  `المشتري`  `المريخ`

## النقاط والشارة

- نقطة لكل إجابة صح
- 🏅 **"عارف كل حاجة"** — 20 إجابة صح
