# 🔎 ابحث عن الكلمات

| | |
|---|---|
| **المستوى** | ⭐⭐ متوسط |
| **المهارة** | التركيز وتمييز الحروف |

## الفكرة

مربع كبير مليان حروف عشوائية، وجواه كلمات مخبّية.
الطفل يدوّر عليها ويعلّم عليها.

## إزاي بتتلعب

1. تظهر شبكة حروف + قايمة الكلمات المطلوبة
2. الطفل يدوّر على الكلمة (أفقي · رأسي · مايل)
3. يسحب بصباعه من أول حرف لآخر حرف
4. الكلمة تتلوّن وتتشطب من القايمة

## مثال

> **الكلمات المطلوبة:** شمس · قمر · نجم
> الطفل يلاقيهم وسط الحروف ويعلّم عليهم

## النقاط والشارة

- نقطة لكل كلمة يلاقيها
- 🏅 **"عين الصقر"** — كل الكلمات في أقل من 3 دقايق
