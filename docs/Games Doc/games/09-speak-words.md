# 🎤 نطق الكلمات

| | |
|---|---|
| **المستوى** | ⭐⭐ متوسط |
| **المهارة** | النطق الصحيح |

## الفكرة

الطفل بينطق الكلمة بصوته، والميكروفون بيسمعه ويقوله نطقها صح ولا لأ.
مفيدة جدًا في اللغات.

## إزاي بتتلعب

1. تظهر صورة أو كلمة
2. الطفل يضغط على زرار الميكروفون
3. ينطق الكلمة بصوت واضح
4. اللعبة تسمعه وتقوله صح ولا يجرّب تاني

## مثال

> 🍎 **الصورة:** تفاحة
> الطفل يقول: **"تفاحة"** → ✅

## ملاحظة

> محتاجة **ميكروفون** ومكان هادي شوية.
> لازم يظهر تنبيه للطفل قبل ما اللعبة تفتح الميكروفون.

## النقاط والشارة

- نقطة لكل نطق صح
- 🏅 **"صوت واضح"** — 10 كلمات صح
