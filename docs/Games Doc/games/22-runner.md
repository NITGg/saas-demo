# 🏃 الجري التعليمي

| | |
|---|---|
| **المستوى** | ⭐⭐ متوسط |
| **المهارة** | أي مادة + سرعة رد الفعل |

## الفكرة

شخصية بتجري لوحدها في طريق، والطفل بيوجّهها.
في الطريق إجابات — يجمع الصح ويتفادى الغلط.

**أكتر لعبة بتحمّس الأطفال الأكبر** — لأنها بتحسّ إنها لعبة حقيقية مش اختبار.

## إزاي بتتلعب

1. يظهر السؤال فوق الشاشة وفضل ثابت
2. الشخصية بتجري وبتقابل صناديق عليها إجابات
3. الطفل يحرّك يمين وشمال أو ينطّ
4. لمس الإجابة الصح → نقطة ⭐ · الغلط → يخسر قلب ❤️

## مثال

> **السؤال ثابت فوق:** أي دول من الثدييات؟
> صناديق جاية: `🐟 سمكة` `🐘 فيل` `🐍 تعبان`
> يجمع الفيل ويتفادى الباقي

## النقاط والشارة

- نقاط على المسافة + الإجابات الصح
- 🏅 **"عدّاء سريع"** — مرحلة كاملة من غير ما يخسر قلب
