# 🃏 كروت الذاكرة

| | |
|---|---|
| **المستوى** | ⭐ سهل |
| **المهارة** | التركيز والذاكرة |

## الفكرة

كروت مقلوبة على وشها، والطفل يقلب اتنين في المرة
يدوّر على الصور المتشابهة.

**من أنسب الألعاب للصغيرين** — مش محتاجة قراية خالص.

## إزاي بتتلعب

1. الكروت كلها مقلوبة
2. الطفل يقلب كارت، وبعدين كارت تاني
3. متشابهين → يفضلوا مفتوحين ✅
4. مختلفين → يترجعوا مقلوبين تاني
5. كل الكروت تتفتح → خلصت

## مثال

> 12 كارت = 6 أزواج
> ممكن تكون صور حيوانات، أو حرف مع صورته، أو مسألة مع إجابتها

## النقاط والشارة

- نقاط أكتر كل ما عدد القلبات أقل
- 🏅 **"ذاكرة قوية"** — لوحة كاملة في أقل من 20 قلبة
