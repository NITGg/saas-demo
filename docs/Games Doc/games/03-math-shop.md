# 💰 متجر الحساب

| | |
|---|---|
| **المستوى** | ⭐⭐ متوسط |
| **المهارة** | الجمع والطرح وحساب الفلوس |

## الفكرة

الطفل عنده فلوس ولازم يشتري حاجات من المحل،
يحسب المجموع، ويعرف الباقي كام.

## إزاي بتتلعب

1. الطفل يستلم مبلغ (مثلاً 50 جنيه) وقائمة مطلوبة
2. يختار المنتجات من الرف
3. يحسب المجموع
4. يدفع ويقول الباقي كام

## مثال

> معاك **50 جنيه**
> اشتري: 🍎 تفاحة (12) + 🥛 لبن (18)
> **المجموع؟** → 30
> **الباقي؟** → 20

## النقاط والشارة

- نقاط على المجموع الصح + الباقي الصح
- 🏅 **"تاجر شاطر"** — 5 عمليات شراء بحساب مظبوط
