# 🧮 صياد الأرقام

| | |
|---|---|
| **المستوى** | ⭐⭐ متوسط |
| **المهارة** | الحساب الذهني السريع |

## الفكرة

أرقام بتنزل من فوق زي المطر، والطفل بيحرّك السلة تحت
عشان يمسك الرقم اللي بيحقق المطلوب — ويسيب الباقي يقع.

## إزاي بتتلعب

1. يظهر المطلوب فوق (مثلاً: "امسك اللي يساوي 12")
2. أرقام تبدأ تنزل
3. الطفل يحرّك السلة يمين وشمال
4. مسك الرقم الصح → نقطة · مسك رقم غلط → يخسر محاولة

## مثال

> **المطلوب: أرقام تقبل القسمة على 3**
> بتنزل: `9` `7` `12` `5` `18`
> يمسك: 9 و 12 و 18

## النقاط والشارة

- نقطة لكل رقم صح
- 🏅 **"صياد ماهر"** — 20 رقم صح من غير غلطة
