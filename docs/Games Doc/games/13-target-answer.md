# 🎯 اختار الإجابة

| | |
|---|---|
| **المستوى** | ⭐ سهل |
| **المهارة** | أي مادة + سرعة بديهة |

## الفكرة

نفس فكرة السؤال والاختيارات، بس الإجابات مكتوبة على **أهداف بتتحرك**
والطفل بيضغط على الهدف الصح قبل ما يهرب.

## إزاي بتتلعب

1. يظهر السؤال فوق
2. أهداف تبدأ تتحرك على الشاشة، كل هدف عليه إجابة
3. الطفل يضغط على الهدف الصح
4. صح → الهدف يتفرقع ونقطة · غلط → يستنى السؤال اللي بعده

## مثال

> **إيه عاصمة مصر؟**
> أهداف بتلف: 🎯 `الإسكندرية` 🎯 `القاهرة` 🎯 `أسوان`

## النقاط والشارة

- نقاط أكتر لو ضغط بسرعة
- 🏅 **"تصويبة دقيقة"** — 10 أهداف صح ورا بعض
