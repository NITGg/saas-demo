# 🎮 ركن الألعاب

صفحة ألعاب تعليمية للأطفال، لينك ثابت في النافبار جنب "كورساتي".

---

## المشكلة

الأطفال بيدخلوا المنصة، بيخلّصوا اللي عليهم، وبيخرجوا.
**مفيش حاجة بترجّعهم.**

## الحل

مكان ثابت وواضح فيه ألعاب تعليمية قصيرة.
كل لعبة بتدّي الطفل **نقاط وشارات** — عشان يرجع من نفسه.

## قواعد كل لعبة

القواعد دي بتنطبق على **كل** لعبة في ركن الألعاب من غير استثناء:

| القاعدة | التفاصيل |
|---------|----------|
| ⏱️ **قصيرة** | من 3 لـ 8 دقايق. أطول من كده الطفل بيسيبها |
| 🎯 **مهارة واحدة** | كل لعبة بتدرّب على حاجة واحدة بس |
| 🔊 **صوت مع كل نص** | حتى للي بيعرف يقرا |
| ✅ **فيدباك فوري** | يعرف صح ولا غلط على طول |
| 💚 **الغلط مش عقاب** | "جرّب تاني 💪" مش "درجتك 40%" |
| ♾️ **محاولات غير محدودة** | يعيد اللعبة براحته |
| 🚫 **من غير ضغط وقت** | إلا لو اللعبة نفسها فكرتها السرعة |
| 🖼️ **صور قبل الكلام** | أيقونات وأزرار كبيرة، نص قليل |
| 🏅 **نقاط وشارة** | كل لعبة بتدّي نقاط، وفيه شارة لما يوصل لهدف |
